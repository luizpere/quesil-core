🎯 Sobre o ThinkinOS

O ThinkinOS é uma plataforma inovadora que combina a potência de assistentes de IA com uma interface de sistema operacional completa.

✨ Principais Recursos

  • 🖥️ Desktop Virtual com ícones e aplicativos

  • 🧠 Sistema de Memórias persistente
  • 🔌 Multi-Provedores de IA
  • 📊 Dashboard Analítico

📥 Instalação

Pré-requisitos

  • Python 3.10 ou superior
  • pip (gerenciador de pacotes Python)
  • Git

Passo a Passo

  1. Clone o repositório 
    git clone https://github.com/luizpereiratj/thinkinos-platform.git
cd thinkinos-platform
  2. Crie o ambiente virtual 
    python3 -m venv venv
source venv/bin/activate
  3. Instale as dependências 
    pip install -r requirements.txt
  4. Execute a aplicação 
    python app.py
  5. Acesse no navegador 
    http://localhost:5000

🧠 Sistema de Memórias

Sistema de memórias para armazenar informações importantes:

📝 O que são Memórias?

Memórias são notas pessoais que ficam salvas permanentemente no sistema.

Como Usar

  1. Acesse /memories ou clique no ícone 🧠 no Desktop
  2. Digite sua memória no campo de texto
  3. Clique em "💾 Salvar Memória" ou pressione Ctrl + Enter
  4. Para excluir, clique no botão 🗑️ ao lado da memória

🔌 API do ThinkinOS

API REST completa para integração:

Endpoints Principais

  • GET /api/historico - Lista todas as conversas
  • GET /api/conversa/{id} - Busca conversa específica
  • POST /api/chat - Envia mensagem para IA
  • GET /api/memories - Lista memórias
  • POST /api/memories - Adiciona memória
  • DELETE /api/memories/{id} - Exclui memória
  • GET /api/config - Busca configurações
  • POST /api/config - Atualiza configurações
  • GET /api/tema - Busca tema atual
  • POST /api/tema - Atualiza tema

❓ Perguntas Frequentes

Como mudar o provedor de IA?

No chat, clique no botão do provedor desejado. O provedor é salvo e usado nas próximas mensagens.

Como exportar uma conversa?

Pressione Ctrl + E. A conversa será baixada em Markdown.

Como mudar o tema?

Clique no botão 🎨 no canto inferior direito do Desktop.

As conversas são salvas?

Sim! Todas as conversas são salvas automaticamente no banco de dados.

Posso usar sem chave de API?

Sim! O Groq já vem configurado e é gratuito. Para outros provedores, adicione sua chave em /configuracoes.
