Instalação em 3 Minutos

Sem ISOs complicadas. Sem configurações de kernel. Apenas Python.

# 1. Clone o repositório git clone https://github.com/luperesil/thinkinos.git # 2. Entre na pasta e instale as dependências cd thinkinos && pip install -r requirements.txt # 3. Inicie o sistema python3 app.py

Acesse depois em: http://127.0.0.1:5000/desktop
