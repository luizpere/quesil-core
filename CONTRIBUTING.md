# Guia de Contribuicao - ThinkinOS v2.0

## Como configurar o ambiente
1. Clone o repositorio.
2. Crie o ambiente virtual: python3 -m venv venv && source venv/bin/activate
3. Instale as dependencias: pip install -r requirements.txt
4. Rode o servidor de DEV na porta 5002: python app.py

## Onde contribuir
1. Novos desafios: Adicione novos dicionarios na lista DAILY_CHALLENGES no app.py.
2. Melhorias de UI/UX: Edite os arquivos dentro da pasta templates/.
3. Correcao de bugs: Procure issues marcadas ou reporte novas.
