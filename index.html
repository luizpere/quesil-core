Quesil Core

Plataforma de Orquestração de Agentes de IA

📖 Sobre

O Quesil Core é uma plataforma web local de produtividade e orquestração de inteligência artificial, inspirada na constelação de Órion.

⚡ Funcionalidades

  • Múltiplos assistentes de IA especializados
  • Gerenciador de arquivos integrado e Terminal web
  • Code review automatizado (Ghorak)
  • 100% local e privado
