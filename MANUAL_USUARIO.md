# Manual do Usuario - ThinkinOS v2.0

## 1. Escolhendo seu Nivel
- Nivel Leigo (Ana - Rosa): Para organizacao pessoal, bem-estar e autoconhecimento. Apenas converse na barra de texto.
- Nivel Intermediario (Carlos - Azul): Para quem esta aprendendo a programar. Leia o card azul e clique em 'Abrir no Editor'.
- Nivel Avancado (ThinkinIA - Roxo): Para desenvolvedores e sysadmins. Desafios de automacao Linux e scripts de sistema.

## 2. Dicas de Conversa
- Com a Ana: 'Quero organizar minha semana', 'Me ajude a criar um habito'.
- Com o Carlos: 'Me explique como funciona um loop for', 'Me de uma dica sobre o desafio'.
- Com a ThinkinIA: 'Como automatizar backup com cron?', 'Script para monitorar uso de disco'.

## 3. Perguntas Frequentes
- O botao 'Abrir no Editor' nao aparece! Isso e normal no nivel Leigo.
- Posso salvar minhas conversas? Sim! Clique em 'Historico' no canto superior direito.
- O editor nao abre o codigo! Recarregue a pagina com Ctrl + Shift + R.
